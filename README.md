# 📈 Stock Portfolio Manager

A **full-stack stock portfolio management application** that allows users to track investments, manage multiple portfolios, analyze profit/loss, calculate taxes, and export data in Excel/PDF format using real-time stock prices.

---

## 🚀 Project Overview

The Stock Portfolio Manager helps users monitor their stock investments efficiently. Users can create portfolios, add stocks, fetch live prices using multiple stock APIs, calculate returns, track holding duration, and export reports.  
Built with a **secure, scalable MERN-stack architecture** and a modern Tailwind CSS UI.

---

## ✨ Key Features

### 🔐 Authentication & Security
- JWT-based authentication
- Google OAuth login
- Secure password hashing
- Protected routes (frontend & backend)
- Session persistence

### 📊 Portfolio Management
- Create and manage multiple portfolios
- Add, edit, and remove stocks
- Track quantity, buy price, and buy date
- Days-held calculation per stock

### 📈 Live Stock Data
- Real-time stock price fetching
- Integrated APIs:
  - Alpha Vantage
  - Finnhub
  - Yahoo Finance
- Automatic price refresh

### 💹 Financial Analytics
- Profit & Loss calculation
- Percentage returns
- Tax slab calculation
- Portfolio-wise and overall summary

### 📤 Export & Reports
- Export portfolio data to **Excel**
- Generate **PDF reports**
- Clean, professional formatting

### 🎨 UI/UX
- Responsive design (mobile, tablet, desktop)
- Tailwind CSS modern UI
- Interactive tables
- Toast notifications
- Smooth user experience
